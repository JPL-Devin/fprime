# `fprime-rust` runtime crate

This crate is the small Rust-side runtime that backs every Rust-implemented
F Prime component generated by [`fprime-rust`](../README.md).  It is **not**
intended to be edited by component authors; it ships the stable types that
auto-generated `<component>_base.rs` modules import.

The runtime intentionally exports a tiny surface:

| Type / fn          | Purpose                                                                |
|--------------------|------------------------------------------------------------------------|
| [`CmdResponse`]    | `repr(u8)` enum mirroring `Fw::CmdResponse::T`.                        |
| [`ParamValid`]     | `repr(u8)` enum mirroring `Fw::ParamValid::T`.                         |
| [`Context`]        | Per-handler context with `cpp_self`, `op_code`, `cmd_seq` and helpers. |

The actual FFI symbols (`rust_<comp>_*`, `extern "C"` blocks) live in the
per-component generated module so the linker can deduplicate them.  See
`../docs/design.md` for the architectural rationale.
